# meta/

Thin layer over the Model API (Responses with strict json_schema, SAM, Voice WebSocket, Image). Every call emits a `model_call` event with cost; daily spend cap (the VN day the store recorded the call, `ingested_ms`, not the event's `ts_ms`); retry/backoff on 429.

A call that gets no reply (cancelled by a worker lane's time limit, or no connection) still emits a `model_call`: `ok=false`, `error` `cancelled` or `transport_<error class>`, cost 0. Its usage never came back, so the provider may still bill it; count these when reconciling with Billing.

Per-session cap: with `MODEL_SESSION_CAP_USD` set, a session whose `model_call` spend (all time, `/api/cost?session=<id>` → `session_usd`) has reached it makes no more calls: `BudgetExceeded("session_cap")`, a `model_call` with `ok=false` and `error="session_cap: spent 8.0000 USD, cap 8.0 USD"` (the spend and cap at the refusal) in that session, no request sent. `daily_cap` / `total_cap` stay bare, as the console matches them. `MODEL_SESSION_WARN_USD` logs a warning once per session. Unset, nothing is checked per session. `/api/cost?session=<id>` also returns `session_cap_usd` and `session_warn_usd` (null when unset); these are the app process's values, while each worker's meter reads its own environment, so set the variables for both. Overshoot limit: nothing is reserved ahead of a call, so calls already in flight when the cap is crossed still complete and can take the session over it. A voice stream is checked only when it opens: a stream already open is not cut at the cap and runs to the end of its play.
