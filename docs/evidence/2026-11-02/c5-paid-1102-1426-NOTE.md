## Cause (from PR #102)
- PR #97 called `queue_cutout` from `on_product_seen`, so the cut-out's card version listed the product_seen in
  `caused_by`.
- `worker/attachments.py` records a product_seen's card versions when its handler returns; the cut-out version came
  later. `app/attachments.py` `check_evidence` then saw a different set of versions for that frame and returned False,
  and every later comment's attachment stayed uncovered until it expired.
- The unpaid dry mode (`measure.c5 --dry`) emits no `comment_attachment` events, so the dry check on PR #97 could not
  show this.
- PR #102 adds `test_card_versions_caused_by_a_product_seen_are_final_when_its_handler_returns`, which fails on a
  checkout of `4ed3041` and passes after the revert (output in PR #102). PR #103 later starts the cut-out at the draft
  and posts no version from it, which keeps this test green.
