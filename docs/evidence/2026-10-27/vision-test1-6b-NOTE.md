# Scope of the 6b vision evidence

- The 6b prompt was tuned on 20 frames of test1 (`vision-test1-6b20-*-1027-1947.json`).
- The 351-frame gate (`vision-test1-6b-*-1027-1950.json`, ledger session `probe-test1-6b-1950`) was measured on the same video, in one run.
- No second video has been measured. The JSON files are kept as the run wrote them.
