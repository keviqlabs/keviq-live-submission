## Definitions changed by the review (HQ 03:48 VN)

- **Right price**: a speech line is `[start_ms, end_ms]`. The heard price is right when it equals the gold price at
  `end_ms`, or when the line overlaps the item's `price_changes` window and the price is either gold price of the
  item. The scripted shop and the scorer call the same `Gold.right_price`.
- **Proposal accuracy**: right card and right price against the gold and windows only. What the shop did with a
  proposal (used, fixed, replaced, dropped) does not make it right or wrong.
- **Situation 2**: a wrong proposal fails only when it is used; replaced or dropped passes, since it was blocked. A
  right proposal passes when used, fixed or replaced. Outcome `other` is listed beside the verdict and not scored.
- **Interventions**: a card version with `edited_by == "seller"` whose price differs from the version before it,
  plus an order event with actor `seller`. It applies to the total, per hour, by cause and the per-loop column.
  This differs from `core.c5`, which counts every `edited_by == "seller"` version (worker versions copy that
  field). `core.c5`'s count is kept beside the total as `core_c5`; `core.c5` is not changed. The threshold stays
  10 per hour. The runner's retire versions now carry `edited_by: None`.
- **Reference n**: the A2 denominator, current / previous with a gold item; unresolved is scored in order_ids. The
  field is adapted from core.c3 (the card the comment's latest label drafted); core.c3 is not called as-is.

## Caveats

- One dry loop, not five. Gold labels, stored vision rows and the rule price reader stand in for the models.
- The shop and the customers are scripted. The shop's rule changed with the fixes, so its actions and the
  intervention count are not comparable one to one with the first run.
- The dry restart drops worker state inside one process; it is not a process restart. A continuous 30-minute
  worker run is not proven.
- The receipt image half is NOT_RUN: 0 of 2 receipts carry an image.
- One loop gives n = 28 references, below the 50 the target needs.
- Interventions here follow the review's definition; `core.c5` still counts copies of `edited_by`. A core change
  is a separate follow-up.
